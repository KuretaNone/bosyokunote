# 2025-11-04
考える時間
一人で考える時間を作ってしまうと死にたくなる

どうして死にたいのかを考えてみる

自分の人生はまだ23年間しか生きていません。

23年って案外短いものです。

特に学生を終えて、社会人になってからの5年間はものすごく一瞬のように感じます。
正確には4年半暗いですけどね。

閑話休題。

最近ふと「死にたいなぁ」と思う瞬間が増えました。
現在、彼女が家に帰省をしているのが主な心あたりです。

彼女が実家に帰省して何が起こったかというと

- 一人の時間が増えた
    - つまり、一人の時間が増えたということです
    - 暇な時間が増えたのでひとりで考え事をするようになりました
    - そこで「死にたいなぁ」とふと思うことが増えました。
- さみしい
    - ひとりはさみしいものです。あまりにもさみしい
    - 彼女は別に寂しくないみたいです
- 彼女が僕のことを「もう好きじゃない」
    - これは直接いわれました
    - 彼女のは（男友達を含む）お友達と朝まで飲たいみたいです
    - あと私のためにはもうがんばりたくないみたいです
    - もちろんこうなったのは私にも大きな原因があります

さて、私は何故「死にたい」のでしょうか。
死とはすなわたち、生の反対というわけです。

「生きたい」という目標がないというのが大きな原因でしょう。

- 仕事で名を残したい
- まだ、俺には表現したいことがある

みたいな壮大な目標はありません。

呆然と **結婚したいなぁ** くらいは思っていました。
しかし、先日の「好きじゃない」宣言時に私は**「あなたと結婚してるところが想像できない」**といわれました。

これ、今の彼女の前の彼女、元カノとわかれる時にいわれた言葉でした。

ここで思うわけです。

あれ、**それじゃあ結婚向いてなくね？**というわけで二人の女性から、「結婚生活が想像できない」といわれました。

多分僕が結婚したくても僕自身という人間は「結婚をしてはいけない人」というわけです。向いてないらしい。

子供は好きなんですけどね…。
好きという気持ちだけではダメ見たいです。

人間難しい。

さて、私の人生のなんとなくの目標「結婚」も打ち砕かれたわけです。

あと僕のやりたいことなんて開発くらいしかないです。(ソフトウェア開発のことだよ！) 

でも、開発も開発がやりたいだけで、何か作りたいものがあるとか、内に秘めた壮大な計画があるとかもありません。

自分の中で漠然とした抽象的な目標や想像なんてものはすべて幻想でしかなく、具体性や再現性のないものには価値がないと思っています。

想像や幻想がダメというわけではなく、それをアウトプットする気概を持って初めて価値があると思っている節があります。

多分。勢いで書いているので、実際は違うかもしれません。


話題から外れすぎです。

「死にたい」という気持ちは本当は「生きる目標」が砕かれ、「具体性」を失ったからです。

では新しい人を探せばいいじゃない。という方。あなたが正しいです。

でも上のことほんの数日前で私はまだ何も立ち直ってはいないし、何なら僕はまだ彼女のことが好きです。

今の仕事がうまくいってないということもありますね。

2年近く同じ開発をしています。

- 自分の技術力不足
- コミュニケーション不足

どちらも足りないことを痛感しました。

また、自己肯定感という言葉は私に対してはあまりにも無縁です。
私は私のことがすきじゃないです。

だって、この文章を読めばわかるでしょう？

文章を書くのも下手。

次いでにいうと、結婚に向いてないくらいコミュニケーションができてないみたいです。

卑屈であるという自覚はあります。もちろんです。

- 書く能力（文章、開発）
- 読む能力（感情の読解力、ドキュメントの読解力）
- 話す能力（コミュニケーション、プレゼン）

私はすべてにおいて、不足を感じています。

鍛えろよとおも思いますが、5年も働いていてどれかが上手くなった手ごたえもありません。
5年相応分のやった時間分の進歩はあるかもしれなくもないですが、それは自然なことであって私自身の能力が高いとか低いとか
そういう次元の話ではないわけです。

死にて～～～～～

こうして、駄文を連ねて、外のに発信できているうちは御の字ですね。
